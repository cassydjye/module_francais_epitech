# Adding a Project

1. Put the original PDF in the appropriate historical folder.
2. Import it with `?url` and add one typed entry to `src/data/projects.ts`.
3. Provide both French and English metadata, the original file path and measured size.
4. Run `npm run validate:data` and `npm run check:all`.

Cards, detail routes, filters, averages and statistics update automatically. Never claim that the source PDF is translated.

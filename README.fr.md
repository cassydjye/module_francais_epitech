# Com'Lab

**Apprendre. Pratiquer. Progresser.** Une plateforme pédagogique bilingue consacrée à la communication professionnelle des étudiants en informatique.

[Ouvrir la plateforme](https://cassydjye.github.io/module_francais_epitech/) · [Documentation technique en anglais](README.md)

Elle regroupe neuf projets historiques, quatre workshops PowerPoint téléchargeables, les cartes Pitch Taboo et sept outils interactifs. Les animateurs peuvent présenter directement les supports ; les étudiants peuvent les revoir et pratiquer après la séance. Aucun compte, backend, suivi ou transfert de saisie.
